# 模型输出显示规则 #286

2026-09-08 用户明确要求放宽校验门槛、展示模型输出。本裁决覆盖此前“引用校验失败就拒绝显示整段结果”的显示规则，不修改 B1 哈希绑定文档。

## 新行为

- 问答、摘要与亮点：引用、结构、数量或长度校验未通过时，保留可读正文并标注“引用未核实”。普通文本响应也可显示。
- 校验仍决定证据资格：未核实输出不生成引用/跳转绑定，不作为已验证学习资产或下一轮证据；不能把模型时间数字当成真实时间。
- 问答使用现有会话存储读回。摘要未核实输出只用于本次显示，不覆盖已验证缓存；若已有旧摘要，区分本次未核实输出与此前已核实内容。
- 只读取模型正文类型字段，普通文本以文本节点显示，不执行 HTML。内部标识、原始错误和凭据不作为展示内容。服务无响应、空响应、无可读正文不能伪造回答；取消、失效请求和来源授权检查不放宽。
- 截图中的旧失败记录在旧版本中未保存回答正文，无法事后恢复；更新后需重试本题。
