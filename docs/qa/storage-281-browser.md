# LG-5 浏览器存储保护补证

2026-09-27，关联 #281。使用生产 LearningRepository、数据库 schema 和备份合并代码，在无头 Edge 的真实 IndexedDB 中验证，不使用个人浏览器资料。网络路由只返回合成测试页面和打包后的测试脚本，其余请求拒绝。

运行前设置 `UX014_PLAYWRIGHT_MODULE` 和 `UX014_CHROME_EXECUTABLE`，然后运行：

```powershell
node tests/learning-storage.browser-qa.mjs
```

每次生成新的 `release-artifacts/storage-281-<时间>/report.json`，记录浏览器版本、源码 commit、脏工作区状态和测试/打包模块哈希。

## 已验证

- 冻结的 v13 合成旧库升级至 v16，21 张旧表全部内容保持不变。
- 在资产写入后注入 metadata 写入的 QuotaExceededError，事务回滚，资产和 revision 均无部分结果。
- 两个基于相同旧内容的并发编辑只允许一个成功。
- 清空后，旧 epoch 的迟到恢复不能重新写入。
- 999 项时并发提交两个新资产，只允许一个成功，最终保持 1000 项。
- 规范序列化恰好 10 MiB 可保存；增加 1 byte 的编辑被拒绝，原文保持不变。
- 关闭数据库并刷新页面后，近上限状态的 SHA256 和全部旧表内容保持一致。

初次开发运行七项均通过（Edge 153.0.4234.48）。该运行基线为合并后的 main `da5946b`；最终脚本收据另外包含测试代码 SHA256，不把尚未提交的测试代码冒充基线已有测试。

## 不覆盖

本脚本是生产仓库模块的浏览器集成测试，不是生产 Worker 时间/内存正式测量。测试不读取用户旧库，不证明真实用户资料升级已通过；配额异常为明确的故障注入，不声称磁盘耗尽或浏览器配额真实触发。页面刷新不是浏览器进程中断，提交期间崩溃和真实多进程竞争仍需另验。#281 保持 open，原阈值、B1/A2、发布边界不变。
