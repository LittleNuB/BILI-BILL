# 多轮学习 Chatbot 与自由拖动 #289

日期：2026-09-09。基线：main `608a81bc04da51b29f8125bfa9ac1fc9b67441d7`，已含输出可读 #287 和范围 #294。

## 实现范围

- 页内问答改为连续消息、底部输入、轻量历史菜单；Enter 发送、Shift+Enter 换行，中文输入法确认不误发送。生成中可以继续写下一问。
- 新学习聊天请求复用原会话存储，不改旧摘要/亮点和 popup 严格问答的证据路径。历史消息区分角色并携带当时参考视频，重试只使用目标轮之前的记录，未核实正文仍可用于理解追问。
- 提示词要求自然区分视频内容与拓展知识；没有授权可用字幕时可一般讨论，不将标题当作视频证据。混合正文使用独立展示标记并保持非验证状态，不注册时间跳转或已验证答案保存；旧已验证引用仍能按原路径核对。
- 真正的 SSE 流式输出，兼容返回普通 JSON 消息的服务；不支持流式的服务可在聊天菜单中关闭流式，失败不自动重发请求。停止保留已显示的部分正文并标为未完成。
- 生成期间约每秒保存一次可读正文，结束时写入最终状态。崩溃重开可读最后成功持久化的部分；不能声称崩溃前最后一个字必然已保存。中断不会自动重发计费请求。
- 会话草稿在本地有界保存最近 32 项；聊天正文沿用原会话容量和清理机制。删除会话同步移除对应草稿，晚到的结果不能复活会话。
- 标题栏拖动、收起态拖动、键盘移动与原八方向缩放共存，保存位置/尺寸、适应视口、可恢复默认位置。正文和按钮不抢拖动，收起/展开不丢草稿。

## 本批边界

- 基础预算以 UTF-8 字节数作保守代理，不是模型精确 tokenizer；默认 32768，可在菜单配置 8192 到 131072，另外预留 2048 输出预算和消息开销。当前正文和问题超限时保留问题并提示调整预算，不截断源材料；历史只带入可容纳的连续近期完整问答，省略较早对话时明确显示提示并保留原记录。提示词不允许声称记得未提供的旧讨论。服务真实窗口仍可能拒绝请求。
- 自动压缩、旧消息检索、超长字幕分段覆盖是 #290；知识库检索是 #291；Wiki 是 #292；长期记忆是 #293，本 PR 均不冒充实现。
- 新聊天中的自然分类来自模型提示，不是独立事实核验；正文标注为模型生成，未证明其陈述全部正确。引用动作不从模型时间数字生成。当前没有新增混合回答到已验证资产的保存捷径。
- 只改页内 Chatbot，不把浏览器 popup 的旧逐题问答称为同步改造完成。原弹窗仍可按原严格路径使用。
- 没有调用用户真实模型、没有读取个人浏览器文件、Cookie、登录态、密钥或真实数据库。合成宿主与模拟响应不替代真实 B 站/真实 provider 验收。
