## 可重复入口

先安装项目依赖并设置三个环境变量：

- `UX014_PLAYWRIGHT_MODULE`：已安装 Playwright 的 `index.mjs` 绝对路径。
- `UX014_CHROME_EXECUTABLE`：用于合成网页检查的 Chromium/Edge 可执行文件。
- `UX014_BROWSER_EXECUTABLE`：支持加载未打包扩展的测试 Chromium 可执行文件。

```powershell
npm run build
# 将源码改动提交后执行，以便收据绑定干净的 commit。
npm run qa:offline
```

入口串行运行六组检查，不依赖个人浏览器或登录；模型回复及视频材料为固定合成数据。结果写入新的 `release-artifacts/offline-<时间>-<commit>/`，保留日志、截图、各组收据以及统一报告。报告绑定源码 commit/tree、测试脚本 SHA256 和全部 dist 文件 SHA256；失败组不被跳过或记作通过，结尾检查源码和构建未变化。必须先构建，入口不宣称任意现存 dist 自动对应 HEAD。

扩展生命周期组新建 `release-artifacts/qa-<随机后缀>` 隔离测试目录，仅由浏览器使用；不读取其 Cookie、profile 或登录态文件，也不将它加入验收包或 Git。进程结束后关闭测试浏览器，隔离目录保留，报告注明未清理。普通 UI 检查使用临时无头浏览器；真实扩展检查阻断 HTTP(S) 外网访问。
