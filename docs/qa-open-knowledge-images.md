# 图文笔记实现与验证

对应 #321，属于 #316 开放知识库迭代，不改变正式版本号。

## 已实现

- 播放器纸笔、相机入口；笔记不暂停播放，点击时间固定，草稿按视频和分 P 持久化。
- 截帧立即保存，后补文字更新原记录；外部编辑过的原段落不会被覆盖。原文字幕与可用的优化字幕分开留存。
- PNG、JPEG、WebP 上传及粘贴，经解码、尺寸和体积检查后重新编码，图片独立保存。
- 无字幕也能记录。当前帧字幕与附近讲解分开显示；页面截屏只裁剪播放器，时间采用实际捕获区间。
- 受限视频帧通过工具栏点击临时授予 activeTab；不添加全站截图权限。授权后重新捕获，不沿用先前时间。
- 图片解读接入现有多轮对话，默认关闭图片模型；主动操作发送实际图片，后续相关对话可保留或移除引用。
- 本地保存与写入目录区分；目录失联不回滚本地记录。旧快捷保存同时镜像到开放知识页。
