# 视频 Wiki 实施合同

2026-09-10，#292，基线 main `4f44e4b394c6ef3b523126945b1bb15de0c21f4c`。以下先冻结本轮技术选择；验证结果另记，不代表功能已完成。

- Dexie v15 新增 `lgWiki` 单行组织状态；BV 唯一页，状态含删除标记。笔记、摘要、摘录正文仍只在原资产中，页面关联按 BV 派生，分 P 使用实际保存记录。
- 组织容量单独限制为 4096 个页记录（含墓碑）、128 个手动主题、8192 个手动关系、序列化 2 MiB；原资产 1000 项/10 MiB 不变。达到上限整体事务失败，不淘汰用户内容或删除记录。
- v14 到 v15 一次性接入以前已经由用户主动保存的资产；没有历史资产不建页。该升级时尚无 Wiki 删除记录。之后浏览、扫描、旧资产备份恢复和旧保存确认不建页；只在真正新增资产的事务中建立/重建页。
- 默认删页保留资产；另勾选删除该视频全部学习内容并在预览后确认才一并删除。删页与资产保存均在资产、库代际、组织状态三表事务中完成。删页递增全库 `lgMeta.epoch/revision`，拒绝之前准备的保存、编辑及恢复；其他窗口未提交内容需重新确认，但草稿不删除。
- 该全库屏障也会取消正在使用知识库的聊天，并在下次省略相关旧讨论；本轮沿用 #291 的保守隐私处理，不谎称只影响当前视频。
- 重建页显示该 BV 仍保留的所有资产，但不恢复旧手动主题归属；按当前内容重新得到自动主题，用户可再次手动调整。主题只聚合视频，不生成正文或综述。
- 自动主题由本地已保存正文词项派生，稳定 ID，不依赖标题独立分类；无足够相关材料不分组。手动名称及加入/排除关系持久化并优先；重算按资产/组织修订缓存，不运行后台模型或远程 embedding。
- 新学习与 Wiki 联合备份使用独立 `bili-bill-learning-wiki` v1 外层，嵌入严格旧 `bili-bill-learning` v1 资产对象及组织状态；原资产格式与字节上限不变。新外层上限为原备份上限 + 2 MiB + 1024 字节；旧包仍可导入，仅恢复资产、不改组织状态。
- 联合恢复预览明确资产按旧规则合并保留本地内容、组织状态由备份替换（包括删页状态和手动决定）；确认后原子提交，预览以来任何库/组织修改均要求重新预览。用户删除最后一条资产后允许视频页留空，备份仍可保存该组织状态；空页只显示身份与零条内容，不生成正文。不导入配置、凭据或额外字幕。恢复时推进库代际防止旧请求复活。
- Markdown 导出只包含当前页现有资产及真实来源，不调用模型。学习页清空同时清空 Wiki；备份能力不包含聊天或长期记忆。

## 待验证

迁移、同 BV 多 P、新保存/幂等重试、删除及迟到保存、重建策略、同份笔记编辑、容量原子性、主题人工优先、备份新旧兼容/取消/并发，以及生产构建桌面与窄屏交互。
