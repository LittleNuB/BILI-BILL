## 工具合同

固定计划最多2个指定视频/分P、16个步骤；只接受概览、多轮对话、字幕优化、图片解读。问题与前序对话依赖在批准前确定，不接受运行时新prompt、任意JS、导航地址或文件路径。批准后只采集选定视频标签；存在多个同目标标签即要求消歧。未开启原声AI字幕时请用户先在页面手动开启；获取失败明确停止，不以标题/简介代替。

字幕复用生产获取和规范化函数，仅替换保存位置，冻结完整当前P的字幕，不写生产笔记或会话。材料绑定视频/P/CID/采集版本/源码/时间/SHA-256；上限20000行、256KB。默认模型文本消息最多64000字节，对话沿用扩展有效上下文设置。固定计划可显式指定`contextBytes`为32768/65536/131072，开发页和每条记录展示此覆盖值，不更改日常对话设置。超限如实报错，不静默截掉主体。字幕不是真值，关键数字和否定仍须对照音视频核验。

图片复用生产 `videoFrame`，仅当前播放器帧，绑定实际捕获时刻及前后15秒讲解。无activeTab整页截图后备，不主动seek，失败停止。选择当前帧应在实际测试计划审查时知悉。

概览复用生产payload/JSON transport/validator；聊天复用生产历史构造器/transport；字幕复用生产32行/4000字符分批和解析；图片复用生产图片payload和供应商分支。使用扩展**当前有效的可编辑提示词与模型**，不读取配置文件或导出密钥。输出上限显式记录，字幕6000，其他2048/8192/16384。字幕每步骤只处理一个预选批次，不隐藏更多调用。

`capture(target)`冻结一次；`run(step)`最多发起一次；相同命令重放只读已有结果。回测使用新计划ID/版本，旧样本/回答/审阅保留。`report(offset,limit,hash)`每段最多12000字符，完整SHA-256防止混合报告版本。`grade(row,grade)`追加评分历史；五维0–2，硬约束和严重失败单列；正文完整保留。无正文归生成失败，不推断不诚实。当前Codex审阅不是独立人工团队或盲审。

模型回归计划通过 `reuseFrom` 指定同一账本内已冻结计划的完整SHA-256，视频ID与分P必须逐一一致，字幕/帧/实际采集时间保持原样且每次生成前复核材料摘要。不重新采集页面；新调用与旧调用累计计费。真实站点采集计划则不使用此字段，两条测试线分别记录。

计划及材料的摘要采用递归排序键的规范JSON，避免浏览器存储调整字段顺序后误报损坏。早期包的原摘要保留：只按其已发布的字段布局重建并核对原SHA-256，不重新签名旧记录、不降低校验或重新采集。语义变化和额外字段仍拒绝。升级测试使用隔离浏览器中的合成历史验证同一扩展ID的新路径加载，保留材料摘要、既有费用和未授权状态。

复用计划缺少旧记录时，开发页仍显示包版本、计划及已存计划标识，不能进入生成。可选恢复包携带工作区中已导出的完整多轮报告链，打包时核对原计划/材料摘要和独立主机账本的全部逐条费用、账本身份；备份完整字节摘要进入构建绑定。用户在开发页点击恢复后才写入，只允许验收账本完全不存在，或已有内容逐项完全等于备份的较早前缀；后一情况只补齐缺失轮次。不同的评分、回答、费用或账本身份均拒绝覆盖。保留原材料、回答、输入摘要、评分与费用；不恢复或导出模型凭据，不授予会话，不采集或调用模型。主机后续连接仍复核原费用账本。包内备份属于本地真实测试材料，不提交 GitHub、不作为公开发行物。

开发包增加 `options_ui` 作为“详细信息”内的验收入口，不新增权限、不改变普通构建。播放器旧内容上下文在更新后同步抛出失效错误时，消息发送器停止播放事件和心跳，保留页面内容，等待用户刷新接入新脚本；普通后台暂时断连仍可重试。这项修复不等于解决浏览器自身的扩展禁用或拦截。

## 连接、会话与计量

Native Messaging host 是浏览器启动的4字节长度帧进程，MCP是Codex启动的JSON-RPC stdio进程；中间使用带192位配对码的Windows命名管道，不开HTTP端口。浏览器源必须匹配安装包限定扩展ID。当前实现仅批准页可授予会话，30分钟有效；MCP/CLI尚无授权或续接工具。这描述现有技术入口，不是永久要求每轮必须人工点击的安全合同。页面关闭/刷新、配置变化、主机断连均撤销当前会话；只读页不抢owner。显式重连只读旧记录，不恢复生成。命名管道同一时间只允许一个主机实例。

2026-10-07用户要求放宽“Never bypass that page”约定，已从工作区Skill移除。用户在会话中的明确任务授权可以覆盖同范围内的会话建立、续接和有限回测；程序提供经校验的入口且工具允许时，Agent可以自动完成，不为例行续接反复申请批准。每轮仍记录固定计划、授权依据、材料与调用数，延续双账本及累计预算。范围/权限/预算扩大、授权撤销或任务完成、未覆盖的新重试仍停止。不得通过改存储伪造授权、改收费记录或禁止的控制渠道实现。可续接的任务级授权接口尚未实现；当前334e1b1运行包仍需页面建立会话，本次文档更新不要求重新打包或重载。

本次授权覆盖选定两视频同范围内的后续修复回测，不重复询问付费许可；每个新计划仍固定新增调用数并保留记录。扩大视频/材料范围需另行授权，旧总48次不扩容。真实验收共享累计10,000,000 token，已知旧32次/58,493；如果旧记录有新增，必须先核对而不能把它清零。旧固定样本工具本身仍保留原1,000,000上限。每次先预留`max(100000, ceil((文本消息UTF-8字节 + 输出上限 + 32768) / 1000) * 1000)`，最多200000；这是保守预算代理，不能宣称精确token计数。扩展账本落盘后再由主机账本落盘确认，才发送模型请求。未知用量占用该条原始预留并暂停；旧记录仍用100000，不抬高已知费用。主机绑定每条预留，禁止事后降低。鉴权、余额、超预留立即停；无自动重试。账本不提供清空按钮。新版本累计此前所有计划收费；主机拒绝新浏览器档案、删除历史和费用回滚。启动新包不能绕过计数。

初次收费实例需确认旧计量仍适用，并不在其他扩展并行测试。旧评测工具本身仍保留原合同，不会被新工具接管或获得额外权限。

用户级安装脚本默认preview，仅显式`-Apply`注册HKCU下的Chrome/Edge专用主机键，不改HKLM/策略。卸载仅移除该包拥有的注册，账本与报告保留。独立账本位于用户审阅的工作区 `release-artifacts/acceptance-state`。未安装前不能声称设备Native Messaging连通。
