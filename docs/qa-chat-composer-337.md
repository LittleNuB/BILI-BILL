# 视频聊天交互整理（#337）

## 本轮范围

- 输入区默认提问。粘贴、上传、截取图片用于待发送附件，不再自动切成笔记模式。
- 待发送图片有缩略图、查看大图和逐张移除入口；字幕引用有移除入口。移除只影响提问，不删除已保存资料。
- 已发送图片归属对应消息。后续沿用的图片单列在对话顶部，可停止引用；重试仍使用失败那一轮的原图片。
- 笔记编辑显示标题和关闭入口，关闭保留草稿。笔记中回车换行；聊天中回车发送、Shift+Enter 换行，中文输入候选确认不发送。
- 参考资料默认折叠；常驻长说明移除；输入区临时状态可关闭；保存后的失败回答仍保留原因和重试入口。
- 回答按 Markdown 展示段落、列表、代码和表格，提供复制、最后一轮重新生成。禁用模型 HTML 和外部图片加载，不把未知引用变成可点击证据。
- 新对话、历史、设置分开。修复未发送的新对话切换到字幕再返回时被旧历史覆盖的问题。
- 图片与引用草稿按视频、分 P、会话隔离。请求结束只清理该请求已发送的附件，不覆盖后来添加的附件或另一会话的文字。

本轮没有改变 AI 授权、知识库数据格式、浏览器权限、模型配置或发布版本。

## 交付边界

- 本轮测试不等于真实 B站、用户配置的 DeepSeek 接口、系统缩放或原生截图权限验收。
- “停止引用图片”控制当前页面中该会话的后续请求，不改写历史消息或删除知识库图片；重新载入页面会从历史最后一轮恢复图片上下文，顶部仍显示可移除入口。
- 未提交图片保留在本地知识资料中；当前会话的待发送选择不作为跨页面重载的持久状态。笔记草稿按现有 IndexedDB 流程保留。
- 不声称旧 A2 或所有发布门禁通过。真实整体验收继续由 #325 追踪，真实图片模型问题继续由 #335 追踪。
