# 开放本地知识库迭代

主任务：[#316](https://github.com/LittleNuB/BILI-BILL/issues/316)。用户已明确批准实施，本文记录 2026-10-03 的范围，不代表功能已经交付。

## 产品闭环

在 B 站边学边记，沉淀到开放的本地知识库；Codex 取用、追溯、补充和确认更新，浏览器继续使用同一份资料。知识库是主工作台，收藏夹属于资料来源；账单、兴趣再平衡与盲盒保留在更多工具。先支持 Windows Chrome、Edge 和 Codex。

前端依据 `release-artifacts/visual-review-20261002-v1/index.html` 的 26 页已认可视觉参考。视觉稿中的示例内容、生成图片和画面完整性不是实际功能验收证据。

## 对旧合同的有限替代

- 第一次成功保存笔记或截图时，允许同时留存当前分 P 已获取的完整字幕。替代旧 bounded learning scope 中“不提升完整字幕”的限制；观看、收藏导入本身仍不触发字幕入库或批量获取。
- 字幕可自动接收与采用，手工指定来源具有优先级；切视频和分 P 必须隔离旧请求。没有字幕时可以记笔记，不能编造视频结论。
- 用户首次主动启用 AI 字幕优化后，可记住偏好，仅自动处理当前视频；撤销授权停止新调用。该例外不授权自动摘要、聊天或全库处理。
- 主动要求 AI 解读图片时允许发送选中的图片及必要上下文。模型能力不匹配必须说明，不能声称看到了图。
- 目录选择器授权的是用户选定目录。新写入限定在选定的 Bili-Bill 区域；其他明确选中的 Markdown 只检索、引用。不得扫描任意磁盘或读取密钥、登录态、浏览器配置目录。
- 视频帧不可捕获时，扩展工具栏的用户操作可临时授予 `activeTab`，只保存播放器区域，不增加全站截图权限。捕获后重新读取播放时间，不能沿用授权前的时间。
- Codex 对个人正文的修改必须展示差异并取得人类确认。已在发起端确认的应用结果进入浏览器后不再重复确认。原始资料不覆盖；AI 补充区的写入权限单列。
- 保留单套按功能可编辑提示词，允许自然语言改写、预览、应用、撤销和恢复默认。提示词不能关闭来源、隐私和修改确认边界。

旧 `gate-contract-0.14-storage-search-and-backup.md`、`development-plan-0.14.md`、`qa-0.14-integration-matrix.md` 保持字节不变。新闭环通过不代表旧 A2/#262 或全部历史发布门禁通过。

## 验收与排除项

- 功能阶段验证公开边界：同一文件格式的浏览器/Node 读写、目录断连队列恢复、分支冲突、迁移幂等性、来源和附件恢复、Agent 提案确认。定向测试随每个实现提交。
- 关键整合点运行全量测试、类型检查、构建与 diff 检查。不因样式变化重跑旧存储矩阵。
- 数据迁移与 Agent 写回集中请求 5.6 Terra/xhigh 复核；工具不可用时记录为缺口，不静默换模型。
- Chrome、Edge 的真实 B 站与真实模型验收另记。合成数据、静态页面、视觉稿不能替代真实站点结论。
- 不覆盖旧验收包。新的交付记录分别列明已实现、合成验证、真实验证、待验收项。
- 不做云同步、通用编辑器、自动跨视频综述、自主知识管理 Agent；主题只关联页面。
