# Codex 本地知识库插件验证

对应 #324，基于 #329 合并后的 main。插件在 `packages/codex-knowledge`，使用官方 MCP TypeScript SDK 2.3.0 的 stdio 服务，共享浏览器文件格式和不可变版本规则。

## 已实现

- 相关片段检索、分段读取页面、查看关联原始资料、读取明确选定的只读 Markdown。
- 新建个人页面、提出正文/标题/主题修改、独立 AI 补充区提案、查看完整差异、用户确认应用、历史恢复。
- 提案绑定知识库身份、基础版本、修改内容和原因；原始资料不能通过修改工具覆盖。
- 应用前通过 MCP elicitation 请求宿主的人类确认，默认不勾选同意；工具参数不能自称已获授权。不支持确认时仅保留提案。
- 等待确认期间若浏览器更新了基础版本，旧提案不会应用。恢复创建新版本，不删除后续历史；已应用提案重试不重复写入。
- 用户可在本地配置单独开启 AI 补充区免确认，个人正文仍不放开。篡改提案的区域声明不能绕过这一限制。
- 只访问已配置目录、指定 Markdown；拒绝路径越界、符号链接、目录联接、硬链接及敏感目录。

## 实际验证

- 插件定向测试 4/4，通过实际 Node 文件、MCP 客户端与 stdio 子进程完成。
- 共享提案的完整性、版本及伪造确认字段另有主项目定向回归。
- 构建包再次以其独立 `server/index.mjs` 入口运行全部插件测试，通过；不依赖打包后的 `node_modules`。
- 当前构建：`release-artifacts/codex-plugin-1791035468066/bili-bill-knowledge`；目录外 `report.json` 包含文件清单和 SHA-256。后续重跑生成新目录。
- 包包含 Skill、便携插件配置、Codex 兼容配置、第三方许可及配置示例，不包含用户目录配置或密钥。

## 限制

- 协议检查中的人类确认由合成 MCP 客户端模拟。尚未声称已安装到当前 Codex 桌面，也未验证该桌面展示确认的实际界面。
- 不支持 MCP 用户确认的宿主会拒绝应用个人正文，不提供未经确认的 shell 写回旁路。
- 浏览器的真实目录选择器、B 站字幕与截图、真实模型和完整闭环由 #325 汇总验收。
- 当前工具接口仍无指定的 5.6 Terra/xhigh，未使用其他模型替代集中复核。该复核缺口保留。
- 本地包版本为独立插件开发版本，不更改 Bili-Bill 正式版本、tag、旧 A2 或商店发布状态。
