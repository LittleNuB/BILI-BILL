# Bili-Bill 0.14.0

Edge 首发准备中，发布者 LittleNuB。本文件不是已上架声明；实际送审与上线状态见 [#365](https://github.com/LittleNuB/BILI-BILL/issues/365)。Chrome 上架暂缓。

## 本轮功能

- 知识库作为主工作台，收藏夹位于资料来源；账单、兴趣再平衡和盲盒保留在更多工具。
- 视频助手按概览、字幕、对话排列；摘要与要点分别展示，多轮聊天支持来源引用、停止、重试、历史与草稿。
- 自动接收当前视频字幕；阅读排版、可选 AI 纠错、字幕直接跳转与返回。
- 时间点笔记、截图笔记、待发对话图片；知识页支持本地图片放大及原始尺寸，窄窗口直接定位正文。
- 视频知识页面与自由命名的个人页面、来源快照、主题关联、版本历史、冲突保留及图文备份。
- 可选本地目录与独立 Codex 插件；限定范围检索、修改提案、人类确认及历史恢复。
- 新手帮助、可选模型配置和按功能编辑的提示词。普通安装包移除开发评测、原始诊断和历史末页等测试入口。

## 安装与升级

正式下载入口在商店审核上线后补充。在此之前，旧 v0.13.0-alpha Release 不是本版本；Code ZIP 是源码。

从开发加载版迁移前，先导出并验证知识库备份。不同扩展 ID 不保证自动共享旧数据，不要卸载唯一数据副本。Codex 插件单独安装，浏览器 ZIP 不包含其安装和系统授权。

## 说明

AI 需要自己的模型服务，费用与能力由该服务决定；没有 AI 或目录配置仍可先记笔记。详见 [隐私政策](privacy-policy.md)。

工程回归、独立复核与真实站点/模型检查分别记录。旧 A2 和历史性能门禁不因本版本号或普通构建通过而自动通过。

目录写入异常可能留下空文件，当前没有自动清理或一键恢复；本地记录与待写队列保留。处理前先备份双方资料，见[目录异常与恢复](user-guide.md#目录异常与恢复)。这项限制仍在正式上线前复核中。
