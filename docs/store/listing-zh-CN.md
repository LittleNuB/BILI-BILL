# 中文商店文案草案

关联 #308，更新于 2026-10-11。对应开放知识库体验候选，正式送审前绑定批准的构建。

## 名称与简短介绍

Bili-Bill

边看 B 站边记笔记，用开放本地知识库与 Codex 复用、追溯和更新学习资料。

当前 manifest 已采用这一产品方向；版本仍为 0.13.0-alpha，正式版本另行批准。

## 单一用途说明

帮助用户把 B 站学习过程中的记录沉淀为可检索、可追溯、可继续使用的个人学习资料。浏览器负责记录与回看；可选本地目录让其他工具继续取用同一份资料。

## 详细介绍

看视频时有所收获，真正需要用时却找不到出处？Bili-Bill 让你边看边记，把画面、字幕和自己的理解留在一起，之后还能在本地工具中继续使用。

**边看边记**
播放器旁的纸笔记录点击时的时间点，相机把画面保存到笔记；没有字幕也能记录。截图保存后可以补充文字，或主动交给支持图片输入的模型解读。视频浮层可拖动、缩放和收起。

**阅读、提问与回看**
助手按“概览、字幕、对话”组织。概览分别显示摘要和带出处的要点；字幕可用时自动接收，点击有效字幕直接跳转。字幕默认排版，AI 纠错可选并保留原文。多轮对话可以引用视频、授权的相关笔记和选中的目标偏好，并区分来源与拓展知识。AI 回答可能有误，请核对重要结论。

**开放本地知识库**
一条视频对应一个知识页面，也可以新建自由命名的个人页面。按主题关联资料，搜索、编辑、查看原始来源和恢复历史。无需配置 AI、目录或 Agent，就能先保存笔记。连接自己选择的目录后，正文、图片和来源保存为普通 Markdown 与独立文件；其他选定 Markdown 只检索与引用，不改写原文件。

**与 Codex 继续学习**
可选的独立本地插件支持检索、读取来源和提议更新。个人正文修改先展示差异并确认，历史可恢复。浏览器扩展不会自动安装本地插件，也不提供云同步或自主维护 Agent。

**接入已有资料**
在“资料来源”选择 B 站收藏夹，一次性导入元数据；再次导入才更新，不会因平台删除或导入不完整而删除本地笔记。仅有收藏信息的条目与已有知识分开。原有内容账单、兴趣再平衡与盲盒位于“更多工具”，不会替你操作 B 站关注、点赞、投币或收藏关系。

**可选 AI 与本地保存**
AI 需要自行配置兼容服务及密钥，服务费用另计。主动生成、提问或图片分析时发送相应任务材料；首次开启字幕 AI 纠错后，会按记住的偏好处理正在使用的视频。资料和目标偏好引用有独立授权。连接检查会发送一条测试请求，不会自动开启学习资料授权。

知识库备份包含已保存页面、图片、原始资料及版本历史，不含未保存草稿、目录权限、外部只读文件和模型配置。首次保存视频笔记或截图时，可同时留存当前分 P 已取得的字幕；单纯观看不会自动将字幕收入知识库。目录不可用时先存浏览器，恢复连接后继续写入。

字幕可用性取决于平台、视频和访问状态；模型是否支持图片取决于服务能力。Bili-Bill 是独立第三方项目，与哔哩哔哩、Google、Microsoft 无隶属关系。
