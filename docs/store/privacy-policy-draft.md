# Bili-Bill 隐私政策草案

未生效。更新日期：2026-10-11。发布主体、私密联系渠道、生效日期和正式政策 URL 待发布者确认。

## 本地处理的内容

Bili-Bill 在浏览器中保存功能所需的 B 站观看及播放记录、收藏和关注同步信息、字幕缓存、聊天、学习笔记、图片、知识页面、来源快照、修改历史、明确保存的目标偏好和配置。它不收集其他网站的完整浏览历史。平台资料读取可能依赖浏览器已有的 B 站会话，插件不要求提交 B 站密码，也不导出 Cookie。

打开视频时可自动接收当前视频的字幕。首次保存笔记或截图时，可将当前分 P 已获取的完整字幕留存为原始资料；单纯观看不会自动收入知识库。原文与 AI 优化版分别保存。

## 图片和目录

截图优先使用视频帧。视频帧受限时，由用户点击扩展工具栏授予当前标签页截图访问，随后仅保留播放器区域；也可主动上传或粘贴图片。保存图片不等于授权发送给模型。

用户通过系统选择器连接目录，扩展只在其 Bili-Bill 管理区域保存新资料。其他选择接入的 Markdown 文件仅供检索和引用，不改写原文件。目录权限失效时需要重新连接；浏览器保留待写内容，并分别显示本地保存和目录同步状态。

可选 Codex 插件是另行安装的本地工具，只访问用户配置范围。它可以读取、检索、查看来源及提议修改；原始资料不覆盖，个人笔记修改先确认，应用后保留历史。不会自动向开发者或云端上传整库。

## 数据何时离开设备

B 站 API、字幕服务和视频封面显示会发起相应网络请求，本地账单同步可定时运行。这些请求与 AI 无关。

使用 AI 时，扩展直接向用户配置的模型服务发送任务输入和认证密钥。输入可能包含问题、有限对话上下文、当前分 P 正文或相关片段；独立授权后可包含相关知识片段和选中目标偏好。主动图片解读会发送选中图片及相关文字，不会默认发送全部图片或整库。摘要、字幕优化和其他入口按各自任务范围传递素材。

文字助手授权本身不会生成回答。字幕 AI 纠错首次主动开启并记住偏好后，会处理正在使用的视频，不批量处理收藏。连接检查发送一条测试请求。关闭对应授权后停止后续使用；已发出的请求无法通过本地删除撤回。

模型服务的留存、训练使用、费用、地区及安全政策由相应服务商决定。不要把不愿分享的敏感信息放入发送材料。开发者是否收集遥测、出售或共享数据的最终商店声明，需要发布者在最终构建网络检查后确认。

## 保存、删除与备份

知识资料与临时缓存、普通聊天具有不同保存规则。知识库归档保留正文、原始资料和历史，不等于删除。数据重置、学习库管理和目标偏好删除，以对应确认范围为准。

新版知识库备份包含已保存页面、图片、原始资料、修改提案和版本历史。已留存的字幕来源也在其中；不包含未保存草稿、目录权限、外部只读文件、模型配置及密钥，也不是整个浏览器数据备份。旧学习资产备份继续使用自身的范围说明。

目录文件和导出备份未加密，请自行保管。删除浏览器数据、卸载或切换扩展身份可能导致未写入目录的资料丢失。商店版与开发加载版 ID 可以不同，迁移前应导出并确认备份，不保证自动沿用原数据。

## 配置与联系方式

端点、模型名称和密钥保存在浏览器扩展的本地配置中，不是操作系统加密保险箱。密钥仅用于对应服务认证，不应写入笔记或反馈。远程服务建议 HTTPS；用户指定的本地兼容服务可使用 localhost HTTP。

普通问题通过 GitHub Issues 反馈，请勿提交私人聊天、备份、密钥或 Cookie。正式发布前补齐发布主体、私密联系渠道、生效日期与政策更新方式。
