# Bili-Bill 隐私政策草案

**未生效，不可作为正式商店隐私政策提交。** 日期：2026-09-27。发布主体、私密联系渠道、适用地区及最终数据流审计待确认。

## 我们处理什么

Bili-Bill 在你的浏览器中保存为功能所需的 B 站观看记录、播放活动、同步的收藏和关注信息、字幕缓存、聊天、学习笔记、视频 Wiki、你明确保存的目标偏好以及配置。它不是整个浏览器历史收集器。读取部分 B 站资料依赖你在 B 站的现有登录状态，浏览器按平台请求使用已有会话；插件不要求你提交 B 站密码。

## 数据何时离开设备

访问 B 站及其字幕服务会向这些服务发起网络请求。配置并使用 AI 时，插件直接向你指定的模型服务发送该任务所需的输入和认证密钥。聊天输入可以包含问题、有限对话上下文、相关视频文本；你另行授权后，也可能包含相关个人笔记和选中的目标偏好。摘要、收藏问答等其他 AI 入口依据其具体授权使用任务素材。

AI 开关本身不触发生成。你可关闭相应授权来停止后续使用；已经发送给模型服务的内容不能通过本地删除撤回。服务商可能记录请求并按其政策处理，是否用于训练、保存多久、存储区域和费用由该服务商决定。不要输入你不愿分享给所选服务的敏感信息。

本地账单同步和统计可能定时运行；它们与用户主动触发的模型请求不同。不能将本产品概括为“完全离线”或“所有内容永不外发”。正式政策中的开发者收集、遥测、出售/共享及用途限制声明，须经最终网络审计并由发布者确认后补全。

## 保存、删除与备份

持久学习内容不会为腾出空间而自动删除。临时缓存与普通聊天存在各自容量和生命周期限制，不提供永久留存保证。你可以在对应入口管理或删除内容；普通数据重置、学习库清空、Wiki 删除和记忆删除的范围不同，以操作确认说明为准。

学习知识备份是未加密的本地文件，包含导出时说明的学习资产及组织信息，不包含完整字幕缓存、普通聊天历史、显式记忆或模型密钥。请自行保管，不要公开上传。浏览器数据清除、卸载或切换扩展身份可能导致本地资料不可用；商店版与开发加载版之间不保证自动迁移。

## 配置与安全

模型端点、模型名与密钥保存在浏览器扩展的本地配置中；不宣称其经过独立加密保险箱保护。密钥仅用于你配置服务的请求认证，不应放入笔记、截图或问题反馈。远程服务建议使用 HTTPS；本地兼容服务可能使用 localhost HTTP。

## 联系与更新

普通问题可通过项目 GitHub Issues 反馈，但请勿提交密钥、Cookie、观看记录、备份文件或私人聊天。正式发布前须提供由发布者确认的私密联系渠道和生效日期；此处不推断或公开个人邮箱。
