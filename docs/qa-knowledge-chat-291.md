# 知识库问答实施与验证

2026-09-10，#291。基线 main `c8f7140dd66d05322c3d01373b89acb8ebbcaa44`。这是功能验证记录，不是正式发布或真实模型效果验收。

## 实施合同

- 独立默认关闭授权；开启本身不读取学习库或发送模型请求。每次主动问题才本地检索，最多 6 个节选、引用序列化合计 8192 字节，并服从原请求剩余预算，不挤掉已能保留的近期完整消息。
- 复用现有有限学习资产。中文分词和少量显式同义词做词项匹配，不是语义向量检索；标题不单独触发匹配。零命中或检索失败可继续一般讨论。
- 原文摘录、个人笔记、已保存模型内容分别标识；模型被要求在结论旁使用本次真实编号。编号点击预览保存时节选，检查来源是否更新或删除，可打开完整原条目。未知编号不可操作。引用存在不等于模型论断已获语义验证。
- 授权保存持久化代际；关闭再开启不会复用上次授权的知识讨论。发送前复查，授权事件立即取消在途请求，库变化以 250ms 非重叠检查取消，包括无新片段的流式连接。已经发送的内容不能从外部服务收回。
- 任一资产修订或授权变化后，下一请求从首个依赖旧知识的轮次起排除后续讨论及摘要；这是保守策略，可能同时排除后来的一般讨论。界面说明省略，原会话记录保留，不删除用户历史。
- 引用随原会话保存，只保存有限节选及定位信息，不复制完整资产。现有会话容量限制不变；学习资产备份不扩展为聊天备份。清除本地设置同时删除知识授权。
- 不新增模型回答保存类型、Wiki 生成入口、全字幕表或后台自动模型请求。未读取真实用户库、浏览器资料、Cookie、登录态或凭据文件。
