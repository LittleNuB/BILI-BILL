## 用户动作与成功结果

1. 首次打开：看到可执行的记录入口，AI、目录和Agent连接不是记录前置条件；不显示任务进度，不用长篇说明填满页面。
2. 保存第一条笔记：反馈指出已保存到浏览器本地，提供查看当前视频笔记的动作；未连目录不能标成已写入目录。
3. 再次打开：能找回内容与来源。新手帮助可关闭、可再次进入，不仅依赖空知识库；不添加必须完成的长向导。
4. 按需启用AI：从当前问题进入对应文字/图片配置与连接检查；原草稿、附件和视频/分P保留；检测成功不等于授权自动发送。
5. 按需连接目录/Codex：说明本地保存与目录写入的区别；用户选择目录或安装Agent，不由新手引导静默执行。
6. 首次展开视频浮层呈现紧凑概览，底部可直接提问；发送后进入对话，有过聊天时重开回到原会话。页签固定概览、字幕、对话。
7. 连续追问：输入区稳定，发送后清空本次已接受的输入，失败可重试原消息；用户下一条草稿不被旧请求清空。
8. 笔记/提问切换：使用不同图标和状态；已输入文字、待发图片、引用按模式隔离，不暗中保存、发送或丢弃。模式改变后截图和上传的目的地同步更新。
9. 图片：待发缩略图可查看/移除，发送后归属对应用户消息；已保存笔记图片的预览不需要模型；无视觉能力或服务失败给准确提示，保留图片。
10. 历史对话：新对话不继承另一会话的待发图片或引用；明确回到哪一条会话；删除有具体对象确认，不能清空所有知识。

## 展示与状态合同

正文区域以用户消息和模型回答为主。来源引用保留可见标记和可展开资料，不能为简洁删除来源区别。上下文用量、分段细节、授权长说明在更多/详情中；阻止继续操作的状态不能藏起来。

| 情况 | 展示位置与操作 | 数据规则 |
| --- | --- | --- |
| 无AI配置 / 未授权 | 当前动作附近一个准确状态及配置/授权入口 | 不阻断普通记录；不自动生成 |
| 待发图片/引用 | 输入区上方的附件/引用条，关闭符号带明确名称 | 移除仅影响待发，不删除已保存笔记或已发送历史 |
| 生成中 | 本次回答一个状态，发送按钮变停止 | 停止保留已收到正文；不触发隐式重试 |
| 完成 | 正文和按需展开的参考资料 | 不常驻重复成功说明 |
| 单条失败 / 中断 | 对应回答一个恢复提示及重试 | 原始输出和附件保留；输入区不复制同一失败；重新尝试绑定原消息 |
| 输入/保存/附件失败 | 当前操作附近一个可关闭提示 | 关闭只清反馈，不清草稿、待写队列、回答或诊断证据 |
| 切视频 / 分P / 会话 | 标题、当前模式和对应草稿同步更新 | 隔离旧异步请求，不把旧回答或图片提交到新上下文 |

截图笔记：捕获并保存，成功后可补文字。截图提问：加入当前待发消息，只有用户发送才调用模型。点击已保存笔记的AI解读是用户主动发送行为，需保留说明与模型能力核对。继续沿用真实时间绑定、原始来源不覆盖和用户授权。

## 分拆、验收与排除

新手路径子Issue负责首次入口、常驻帮助、保存后找回和可选设置返回；对话子Issue负责模式/会话草稿、附件发现性、反馈归属和常见输入交互。复用#335故障分类、#343截图区分、#339字幕跳转；实际发现缺陷回原Issue，避免重复写同一修复。

定向验收：无AI/无目录记录并重开、帮助关闭再打开、设置返回不丢草稿、中文输入Enter不误发、模式切换不串内容、待发与已发图片预览/移除、停止/失败/重试、会话与分P切换、窄浮层和键盘焦点、重开原会话。原生授权及Chrome/Edge真实站点另记；mock不冒充真实结果。

初次使用能迅速找到并完成第一个动作是观察目标，不新增2秒或20秒性能门禁。自动化#345提供证据，不因工具未完成暂停可做的本地定向回归。关键整合点跑全量/typecheck/build，样式不重跑存储矩阵。

不做通用编辑器、云同步、跨视频自动综述、自主维护Agent、默认全库发送、模型供应商扩张、动态账单推荐排序；不修改正式版本或商店送审。界面沿用26页已认可白/浅灰/粉色视觉，不新增一套设计风格。
