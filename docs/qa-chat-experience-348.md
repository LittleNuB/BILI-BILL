# 视频对话体验 #348

本批基于 main `8c7f3149b2063c483eca18266917b23d6b491aa1`，范围为 V0.14 候选包的现有交互修复，不增加新 AI 功能、请求预算、权限或正式版本号。

## 行为变化

- 输入区同时展示“提问”和“笔记”，分别使用对话、纸笔图标及明确选中态。切换仅保留、恢复草稿，不自动保存正文或调用模型；笔记草稿仍按视频、分 P 隔离，提问图片及引用仍按会话隔离。
- 笔记里的“带图提问”只准备图片和问题；已有提问草稿不被覆盖，点击发送才调用模型。聊天粘贴、上传和截图保存不替换当前笔记草稿。成功保存后只结束聊天图片的临时编辑记录，已保存知识页、图片和来源不删除；失败记录保留。
- 图片先完成解码再允许查看。无法读取或解码时出现“重新载入”，可重试或移除待发图片；移除不删除已保存图片。
- 临时反馈按输入模式及会话定位。读取会话失败在工具栏下方集中展示，可以重试、关闭；关闭不删除聊天记录。来源保持可见短标签，生成过程的详细说明折叠在“生成详情”。普通模型正文仍可读，不提高引用真实性口径。
- 中文组字期间，Enter 和发送按钮均不提交。停止等待期间禁用重复停止；失败可重试原问题，正在填写的下一问不被清空。
- 历史操作明确为“重命名当前对话”“删除当前对话”。异步操作不切回已经离开的会话；删除后进入空的新对话，不自动展示其他视频的会话，并清除该会话在前端的草稿、附件及重开指针。
- 后台读取完成不关闭正在操作的历史菜单；回答完成直接采用已读取的记录，取消旧读取的界面更新，不重复读取造成短暂旧状态。
