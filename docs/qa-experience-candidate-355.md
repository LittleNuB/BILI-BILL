## 2026-10-07 自动化交接整合

原自动化会话按用户要求交回产品主会话。本候选在确认两端工作区干净、`f49b5a7` 为共同基点后，使用 `git merge --ff-only a50c494fa96653b89c5bdc13a0c8cc95a4d88886` 接入完整链，不仅移植最后一笔提交。原自动化 checkout 没有被切分支或写入。

接入包括受限 CLI/MCP/Skill、任务续接与撤销、收费账本及未知用量保护，以及生产界面的待发文字/图片恢复、图片依据提示词、字幕纠错的有界请求和扩展失效提示。续接只保留同一任务的授权，不重置预算、暂停或未知收费；退出浏览器、撤销、配置变化等仍终止授权。

候选打包现在自动执行四项零费用页面回归（Chrome、Edge 各执行一次），覆盖任务会话、字幕/分P、笔记/图片/对话、扩展上下文失效。字幕和图文套件不在打包里重复执行。新增合同回归先失败后修复，拒绝旧源码、脏工作区、不同生产包、缺失/失败流程，或把模型调用、个人浏览器读取、真实站点成功混入离线证据的报告。

本轮真实站点及收费模型测试保持暂停；不要求重新配对、不重装或升级当前已安装的扩展。仅以 SHA-256 核对授权目录中的账本未改变，不读取凭据或个人数据库。新增报告绑定源码 commit/tree、生产 bundle 和每项报告哈希，不复用自动化会话之前的成功结果。

GitHub 首次实时查询遇到 TLS handshake timeout；远端 PR/CI 状态及同步结果必须另行实时核对，不能凭交接宣称已推送或通过。
