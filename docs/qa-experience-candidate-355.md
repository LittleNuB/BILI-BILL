## 整合修复

处理 assistant-status、assistant-styles 和图文 QA 的三处冲突，保留截图文字、组合图标、停止中状态、模式选中和新交互测试，未整体采用 ours/theirs。

首次组合 QA 在 844×390、浮层宽 320 的状态复现聊天区域被双行工具栏挤压，时间线 padding 越过输入区。通过窄容器工具栏间距/尺寸约束和低高度时间线 padding 修复；保留全部按钮与目的地文字。新增聊天区域仍可见的断言和失败几何记录，没有放宽原有不重叠检查。一次另行复跑出现无图片模型反馈未展示的超时，原失败报告保留；随后双浏览器回归通过，最终包仍需重新执行同一完整流程，不将单次成功视为该状态总体无风险。

## 验证与打包

定向测试 45/45；图文对话 QA 已通过 Chrome、Edge。最终 `npm run package:knowledge` 在干净提交上串行运行审计、类型、全量、构建、Codex 测试与打包、十项界面流程及 diff-check，结果以新包 `verification.json` 为准。

新增普通候选合同检查：dist manifest 与源码完全一致，版本/权限不改变，无 nativeMessaging、cookies、debugger、外部控制连接、开发评测或原生控制文件。ZIP 逐项读回 SHA-256，与源目录清单一致。包内 composition.json 及其哈希绑定纳入范围；截图和日志随本次验证保存，不复用旧包结果。流式 Chrome/Edge 每次创建独立证据目录。

新 Guide 同时展示安装路径、帮助入口、对话/笔记规则、截图去向与待验边界。它是教程，不是可直接运行的扩展；插件由 extension 文件夹加载。
