# 知识页阅读体验 #362

## 发现与修复

本轮在隔离的 Chrome、Edge 中加载普通扩展，使用界面保存、读取和恢复合成资料。发现两处操作问题：

- 窄窗口点击知识页面后，正文仍在列表下方，用户需要再次滚动才能阅读。现在窄窗口将已打开的正文置于列表之前，并在主动打开时定位到正文；后台刷新不会主动抢焦点。
- 已保存的学习图片只展示缩略内容，缺少放大入口。现在附件图片与正文中的本地图片均可打开大图，支持适应窗口、原始尺寸、关闭及返回原位置。键盘 Enter、空格和 Escape 同样可用。

使用已有弹窗、图标和附件读取接口，不更改文件格式、权限、模型请求或正式版本号。外部图片仍不自动加载。

- 全量单元测试 931/931、类型检查、普通构建通过。

## 体验与交付

知识库打开一条页面，点击图片即可查看大图；窄窗口关闭页面后仍可浏览原列表。无需配置 AI 或本地目录。

新包独立生成，包含本次修复、普通浏览器扩展、Codex 插件及安装指南，不覆盖旧验收包。普通扩展不包含提示词评测、自动化验收入口或历史末页等开发探针。

本轮检查使用合成资料，不读取个人浏览器配置，不调用真实模型。真实 B站页面尝试返回 `ERR_CONNECTION_CLOSED`；真实站点、模型、系统缩放、全屏及原生权限选择器仍需后续验收。
