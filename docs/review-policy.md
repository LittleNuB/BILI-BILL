# 独立复核策略

用户于 2026-10-19 取消必须使用 5.6 Terra/xhigh 的限制，授权主 Agent 根据任务选择可用的复核模型，并明确允许使用 6.1 sol。本策略替代所有旧文档中对特定复核型号的硬性要求，不降低复核、测试、隐私或发布门槛。

- 按风险选择可用模型和推理强度，不再因为某个指定型号下线而阻塞全部工作。数据迁移、路径权限、并发冲突和 Agent 写回应使用独立 reviewer 与充分推理强度。
- reviewer 不参与被审实现；固定待审提交，给出具体文件、行号、失败情景、严重程度和测试缺口。记录实际模型、推理强度和待审提交，不冒充其他模型。
- P0/P1 修复前不放行；P2 必须修复或记录明确处理决定及残余风险。发现必须保留，定点复核不能冒充新一轮全面审查。
- 规范与需求两个轴分别核对；工具可执行检查不代替语义审查，代码复核不代替真实站点、模型、原生权限或数据恢复验收。
- 不改写已有复核历史、旧包或收据。冻结的性能/开发计划保持原字节；旧文档中的型号要求不再是当前执行限制。
- 没有实际执行的复核仍是未完成，不因为工具或测试成功就标为通过。

本轮 #365 使用 `gpt-6.1-sol / xhigh` 独立复核候选的数据迁移与 Agent 写回；具体源码、发现及修复另存本轮报告。
