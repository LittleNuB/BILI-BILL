# 开放知识库基础验证

对应 #318，基线为 #326 合并后的 main。此记录只覆盖共享格式、目录适配器、浏览器持久化和迁移基础；没有宣称新 UI 或完整学习闭环已完成。

## 已验证

- Markdown 中文正文、独立 AI 补充区、来源身份和 LF/CRLF 读回；内容校验失败不进入有效历史。
- 同一修订重试不会重复；离线与外部修改保留为两个版本；合并版本保留双方父版本。
- Node 目录适配器拒绝绝对路径、父路径、Windows 设备路径和指向范围外的链接。
- 原字幕不覆盖；优化稿时间轴必须与原稿一致；非 PNG/JPEG/WebP 附件拒绝。
- 本地笔记、来源、图片在同一事务提交。失败保存不会把新完整字幕单独留存。
- 页面重开保留笔记和草稿，权限失败保留队列，重连读回外部版本。
- 迁移保留旧身份、原始记录、主题及关联的完整来源副本，不修改旧数据表；重复执行不重复建页。
- 清除期间的旧读回不能重新写入浏览器，目录中的用户文件保持不变。
- 数据库升级新增三张表，原有 21 张 v13 表的结构和内容继续受回归测试保护。

- `npm test`：817/817 通过（全量整合检查）。之后的换行兼容补充运行定向测试，并由 PR CI 再次运行全量。
- 类型检查与构建通过，最大压缩 JS chunk 仍小于 500,000 字节。
- `tests/open-knowledge.browser-qa.mjs` 在 Chrome 154.0.8037.93 和 Edge 154.0.4258.53 通过。
- 浏览器测试使用真实 IndexedDB 和 OPFS 文件句柄，包含句柄持久化、页面重开、与 Node 相同文件字节的往返读写。
