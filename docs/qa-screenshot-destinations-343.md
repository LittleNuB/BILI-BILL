# 截图入口去向 #343

浮层顶部和播放器的截图入口展示“截图笔记”，使用纸笔与相机组合图标，辅助名称为“截图到笔记”。点击沿用原立即保存与补充文字流程。

底部输入框在对话模式展示“截图对话”，使用对话气泡与相机组合图标，辅助名称为“截图到对话”。图片加入待发送区，可以预览或移除；用户点击发送才调用模型。底部切换到笔记模式时，图标和名称同时切换为“截图笔记”。

既有图片持久化和来源关联不变：对话截图也保存源图片供后续读取，移除待发图片不删除已保存记录。此改动不增加权限、弹窗确认、模型调用或新的数据格式。

验证复用 `tests/quick-images.browser-qa.mjs`：生产内容脚本与真实IndexedDB，Chrome/Edge检查笔记保存、两个入口的去向、对话截图不自动发送、待发送预览和移除、笔记模式切换及宽窄布局。站点、消息桥和模型响应是合成数据，截图不能代替真实B站验收。

最新main尚未包含#340的菜单互斥修复；在该基线上Edge完整回归会触发既有历史/设置菜单问题。截图PR保持独立范围，整合验收包包含#340、#342及本改动后验证完整流程。极窄浮层只隐藏顶部按钮的短文字，保留不同图标、辅助名称与悬停提示，底部仍显示截图去向。
