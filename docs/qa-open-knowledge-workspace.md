# 知识工作台与收藏来源验证

对应 #322，基于 #328 合并后的 main。工作台使用 #318 的共享文件和浏览器持久化，不是视觉稿占位页面。

## 已实现与验证

- 知识页成为默认工作台；视频页面与自由命名个人页面共存。主题筛选、有限片段搜索、正文编辑、自动草稿、归档与版本恢复可用。
- Markdown 禁用内嵌 HTML，不自动加载远程图片；外部链接与来源链接先预览。图片附件使用本地文件，不加入旧笔记正文容量合同。
- 目录不可用时仍可保存；同步状态区分本地保存与目录写入。外部并发修改保留双方版本，合并与恢复均创建新版本。
- 收藏夹首次无默认勾选；只在用户操作后读取所选收藏夹，重复导入不重复创建页面。收藏元数据与已有笔记区分，空列表和不完整导入不删除本地笔记。
- 显式导入 Markdown 副本后可检索、引用原始资料，原文件不改写。该入口不是对外部文件的持续同步。
- 历史容量上限在不可变写入前检查；达到上限仍能读取已有历史。晚到的草稿保存不能撤销用户的清除操作。
- 旧版收藏、视频笔记工具保留在更多工具；旧的引用、备份与数据库合同继续回归。

## 运行结果

- 全量 Node 测试通过；最后补充的历史容量边界定向回归通过。
- `npm run typecheck`、`npm run build` 通过；Markdown 依赖升级后 `npm audit` 无已知漏洞。
- `tests/knowledge-workspace.browser-qa.mjs` 在 Chrome 154.0.8037.93 和 Edge 154.0.4258.53 通过。
- 覆盖中文编辑、关闭重开草稿、连接目录、断连保存、外部修改读回、冲突合并、恢复历史、只读副本检索、收藏选择和重复导入；检查 1280 / 768 / 390 宽度，无横向溢出或页面异常。
- 本轮报告与截图：`release-artifacts/knowledge-workspace-1791034100761/`。后续重跑生成独立目录。
