# 字幕单击跳转与提示词改进（#339）

## 用户决策

2026-10-04：已获取的当前视频字幕，点击即跳转，不再二次确认。

本决策仅替代字幕行、字幕搜索结果点击入口的预览确认步骤。点击本身就是确认；后台仍验证视频、分 P、来源身份、行绑定及操作授权。保留返回跳转前位置和保存所选字幕入口。

划词选中、查找、上/下一个搜索结果、滚动、跟随播放不发起跳转。AI 生成的亮点、问答引用、其他视频及外部链接仍使用原有预览/确认规则。

## 提示词核对

设置页原先显示的是四项表达偏好，不是完整系统提示词。原有实现已经包含：

- 概览：JSON 字段、数量范围、有效证据行、禁止模型计算时间；本地解析与引用验证。
- 字幕纠错：一一对应的 JSON 行数组，保留原文身份与顺序，格式失败不覆盖原文。
- 对话：来源隔离、知识库引用、历史裁剪和禁止虚构来源；原先缺少明确 Markdown 排版规则。
- 图片：偏好与对话系统规则合并；原先图像分析方法、不可见内容与推测的区分不够具体。

## 实现

- 四项默认偏好分别补充任务目标、表达组织、边界和格式。手动保存的自定义配置不覆盖，可手动恢复默认后使用新版本。
- 对话固定规则补充 Markdown、段落/列表/代码块和简答优先；不强制每次回答套用三段模板。
- 图片固定规则明确实际画面与字幕分开、不可见细节不补写。默认偏好细化图表、代码和文字截图的阅读要求。
- 概览固定规则补充摘要/要点/亮点的分工及输出前自检，保留既有 JSON 字段与证据合同。
- 默认提示词和固定合同版本参与概览缓存指纹，避免升级后继续命中旧默认结果。保留旧记录，不自动重新调用模型。
- 设置编辑字段改为“回答风格与偏好”，保留应用预览、撤销、恢复默认及原授权边界。

## 验证与限制

- `tests/ai-prompts.test.ts` 覆盖默认/自定义缓存隔离、配置不覆盖、对话与结构化任务的不同格式要求及纠错行校验。
- `tests/learning-chat.test.ts` 覆盖正文响应、流式解析、重试/取消、图片载荷与错误分类。
- `tests/automatic-subtitles.browser-qa.mjs` 使用生产内容脚本，Chrome/Edge 验证单击字幕/搜索结果即跳转、返回位置、文字选择/搜索导航不跳转及原有晚到字幕、纠错/分 P 隔离用例。
- 完整候选包的全量、构建、双浏览器与打包结果以该包 `verification.json` 为准。

以上是合同与程序行为验证，不是模型语义质量评分。未调用用户官方 DeepSeek 接口，不能宣称真实模型已经稳定遵守格式、纠错准确率提高或所有生成内容可靠。普通模型正文仍保持可读，未经验证的引用不会变成可跳转证据。
