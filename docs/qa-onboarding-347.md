# 新手记录路径验证（#347）

2026-10-06，基于 main `8c7f3149b2063c483eca18266917b23d6b491aa1`，分支 `codex/347-onboarding`。

## 本轮改动

- 知识库常驻帮助：空态沿用现有记录入口，非空也能打开；没有强制配置或任务进度。
- 可关闭的保存和错误反馈，保存后可定位对应页面；浏览器保存与目录写入分别表达。
- 从帮助按需进入文字 / 图片设置，返回知识库恢复编辑草稿及其图片、来源引用。草稿写入失败不跳走。
- 图片模型连接检查复用既有 `TEST_AI_CONNECTION`，使用保存的服务配置和当前图片模型名。只检查文字响应，不能证明图片能力；不保存配置、不开启授权、不发送学习内容。
- 未修改数据格式、迁移、写回确认、字幕跳转或视频聊天布局。视频浮层的模式、附件及反馈打磨归 #348；模型效果和自动化分别归 #341 / #345。
