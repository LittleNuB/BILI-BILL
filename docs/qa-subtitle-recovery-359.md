# 字幕读取恢复 #359

## 真实反馈与证据边界

用户在 7a0d454 体验候选中报告：两个视频已取得字幕，第三个视频 BV1fKeg6mEY4 的播放器已显示中文 AI 字幕，浮层仍显示“暂无字幕”。本轮通过 Edge 只读核对，先观察到该空状态，后观察到同一视频已显示 1045 条字幕；期间 Agent 未刷新、点击字幕开关或重新选择来源，也未调用模型。未核实用户在两次观察之间是否操作过页面。

这证明反馈涉及真实的字幕等待/恢复问题，但不能证明存在“最多两个视频”的限制，也不能确定当时的唯一根因。下述调度缺陷由生产代码的确定性复现确认；新代码尚未替换用户已安装的扩展，不能把旧包后续恢复算作新包真实站点验收通过。

## 已确认的缺陷与修复

`AutomaticSubtitlePoll` 在读取过程中接到播放器通知时，会提前下一次读取时间；旧读取完成后却无条件将它覆盖成 45-60 秒的退避时间。字幕已经出现，插件仍可能等待旧退避。

现在保留读取期间的通知，不新增并行请求。隐藏页仍不轮询，取得可读字幕后停止自动重试，视频/分 P 身份隔离及手动来源选择保持原有规则。无需二次选择字幕，不自动触发 AI。

浮层在无可读字幕且实际读取中显示“正在获取字幕”；已有字幕更新中显示“正在更新字幕”并保留当前可读内容。读取失败或暂未取得时提供普通产品入口“重新获取字幕”。该入口复用现有字幕读取流程，不是新增开发测试接口。
